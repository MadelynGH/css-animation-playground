# Instructions
## About
**CSS Animation Playground** is a tool that allows you to play with CSS animations. I created five different animations: Pulse, Spin, Fade, Slide, and Bounce. Certain CSS properties related to animations are customizable via dropdowns. (Note that the dropdowns may not include all possible property values.)
## Dropdowns
The tool includes three dropdowns, each for customizing a specific CSS property: **animation duration**, **animation timing function**, and **animation direction**. Here are some steps for changing a dropdown:
1. Click on the dropdown box (looks like a rounded rectangle).
2. Click on your desired value.
## Previews
In the tool, you'll see three preview boxes; the previews are designed to show you what your currently configured animation looks like. These each have an element in them that the animation gets applied to; the three preview elements are **a rounded square**, **a circle**, and **an "E" letterform**.
## Code Snippet Copying<
**DISCLAIMER: Code snippet copying can be used with Pulse, Spin, and Fade. It cannot be used with Slide and Bounce.**
<br>
As you are customizing and playing with the various properties, a CSS code snippet displayed below the preview boxes will update. If you want to copy the CSS code to use in your project, click the "Copy" button.<br>In your project, you will have to assign a CSS class of "[lowercase animation name]-animation" to the elements you would like the animation to be used on.
